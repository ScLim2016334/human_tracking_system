# Human Tracking System - Refactored

这是一个重构后的人体跟踪系统，具有人脸识别和遮挡处理功能。代码已按模块化设计重新组织，提高了可维护性和可读性。

## 模块结构

### 1. `config.py` - 配置文件
包含所有系统配置参数：
- 骨架跟踪相关参数
- 主人校准参数
- 遮挡处理参数
- 人脸识别参数
- 姿态检测阈值

### 2. `state_manager.py` - 状态管理器
管理所有全局状态变量：
- 骨架跟踪状态
- 主人信息
- 遮挡状态
- 提供统一的状态访问接口

### 3. `pose_utils.py` - 姿态检测工具
处理姿态检测相关功能：
- 从关键点计算边界框
- 检测"双手叉腰"动作
- 计算IoU（交并比）
- 绘制骨架

### 4. `face_recognition_utils.py` - 人脸识别工具
处理人脸识别相关功能：
- 从图像检测人脸
- 人脸编码和匹配
- 主人人脸识别

### 5. `skeleton_tracker.py` - 骨架跟踪器
核心跟踪逻辑：
- 骨架ID分配和匹配
- 遮挡检测
- 人脸与骨架绑定

### 6. `master_calibration.py` - 主人校准模块
处理主人校准流程：
- 主人人脸记录
- 主人骨架校准
- 主人重新识别

### 7. `visualization.py` - 可视化模块
处理所有显示和绘制：
- UI界面绘制
- 骨架可视化
- 状态信息显示

### 8. `human_tracking_refactored.py` - 主程序
整合所有模块的主程序文件。

## 使用方法

### 运行程序
```bash
python human_tracking_refactored.py
```

### 操作说明

#### 步骤1：记录主人人脸
1. 靠近摄像头
2. 按 's' 键多次记录不同角度的人脸
3. 按 'n' 键进入下一步

#### 步骤2：校准主人骨架
1. 远离摄像头，确保全身可见
2. 做出"双手叉腰"动作
3. 系统会自动识别并校准

#### 步骤3：正常跟踪模式
- 系统会自动跟踪主人
- 处理遮挡情况
- 支持主人重新识别

### 按键控制
- `s`: 记录人脸（步骤1）
- `n`: 进入下一步
- `r`: 重置所有记录
- `q`: 退出程序

## 遮挡处理机制

系统通过以下机制处理遮挡问题：

1. **位置距离检测**: 检测骨架与主人最后位置的距离
2. **遮挡检测**: 监控主人是否被遮挡
3. **人脸重新识别保护**: 遮挡时暂停人脸重新识别
4. **超时机制**: 长时间遮挡后重置状态
5. **ID分配策略**: 为遮挡者分配新ID

## 文件说明

- `human_tracking_refactored.py`: 重构后的主程序
- 其他模块文件: 按功能分离的各个模块

## 优势

1. **模块化设计**: 每个模块职责单一，易于维护
2. **配置集中**: 所有参数集中在config.py中
3. **状态管理**: 统一的状态管理接口
4. **可扩展性**: 易于添加新功能或修改现有功能
5. **代码复用**: 模块间可以独立使用
6. **测试友好**: 每个模块可以独立测试
